---
description: Ревью последних изменений через подагента reviewer, без git, по списку файлов из отчёта
argument-hint: [список файлов или номер модуля]
---

Проведи ревью последних изменений через подагента `reviewer`. Git не используется.

1. Определи список файлов для ревью, в таком порядке:
   - если в `$ARGUMENTS` указаны файлы, возьми их;
   - иначе возьми раздел «Изменённые файлы» из последнего отчёта по модулю в этом диалоге;
   - если номер модуля указан в `$ARGUMENTS`, возьми файлы по его описанию в `PLAN.md` («Результат»);
   - если список определить нельзя, спроси пользователя и остановись.
2. Передай `reviewer` список файлов, номер модуля и ссылку на раздел модуля в `PLAN.md`.
3. Выведи находки пользователю по приоритету: критично, важно, мелочь, с `файл:строка`.
4. Ничего не исправляй без подтверждения пользователя. Предложи, что исправить, и спроси.
