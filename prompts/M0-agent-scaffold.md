# M0. Агентная обвязка и каркас проекта

**Дата:** 2026-11-13
**Модуль:** M0

## Цель
Подготовить среду, чтобы ИИ работал предсказуемо: правила, настройки прав, подагенты, команды, скилл, линтер и `Makefile`.

## Контекст
`AGENTS.md` (обязателен к прочтению), раздел M0 в `PLAN.md`, раздел «Что сдать» в `TZ-YouTube.md`. Git выполняет только пользователь.

## Промпт
> Сначала прочитай файл AGENTS.md.
> Реализуй модуль M0 из файла PLAN.md.

## Критерии приёмки
- `CLAUDE.md` содержит цель, стек, структуру, команды, соглашения, правила агента, формат отчёта и ссылку на `AGENTS.md`.
- `.claude/settings.json` явно запрещает `git`, чтение `.env` и `rm -rf` вне проекта.
- Есть подагенты `backend-dev`, `frontend-dev`, `reviewer`; команды `/module`, `/review`, `/dod`; скилл `new-endpoint`.
- `pyproject.toml` с `ruff` (включая правила `S`), `Makefile` с целями `lint`, `format`, `test`, файл `.gitignore`.
- `make lint` проходит на пустом проекте.

## Результат

Создана обвязка: `CLAUDE.md`, `.claude/settings.json` (запрет git и .env), 3 подагента, 3 команды, 1 скилл, `pyproject.toml` с `ruff` (правила `S`), `Makefile` с целями `lint`, `format`, `test`, `.gitignore`, структура `prompts/`. Проверку `make lint` выполнить не удалось: в окружении нет `ruff` и `make`. Они будут установлены при подготовке backend-окружения в следующих модулях.
